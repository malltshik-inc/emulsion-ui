# Emulsion UI

A browser-based design concept for a minimalist photo editor with a warm editorial aesthetic.

Live demo: https://malltshik.github.io/emulsion-ui

## Overview

Emulsion UI is a static concept mockup exploring how a photo editing interface could feel: tactile, calm, and focused on the image rather than complex tool clutter. It is built as a single-page experience using plain HTML, CSS, and JavaScript.

The project is intentionally visual and experimental. It presents a set of sample scenes, editing controls, and a polished interface inspired by modern creative tools.

## Design concept

This is not a production photo editor or a maintained app. It is a concept-art style prototype for interface exploration and visual direction.

- warm neutral palette
- minimal tool layout
- gallery-style image browser
- adjustment controls for a photo-editing workflow
- compare mode for before/after inspection

## Status

No maintenance is required for this project. It is a self-contained static mockup intended for browsing and demonstration.

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local web server if preferred.
